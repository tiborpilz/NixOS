One flake, six machines, one home directory

This repository is a single Nix flake that describes every computer Tibor runs: a home server, a public VPS, a laptop, a TV box, an old laptop and a WSL install. It also describes a user environment that can be installed on any Linux or macOS machine. The trick that holds it together is simple: you drop a file into the right folder and the flake finds it. Nothing is registered by hand.

    How a host is built

    Every NixOS host gets the same stack of modules. What makes klaus a media server and edge a VPN hub is only which switches its default.nix turns on. Pick a host to light up its switches.

  networking.hostName = mkDefault "klaus";
  specialArgs = { inherit lib inputs system; };

    ../default.nix                 # repo-root defaults

    Single sign-on
    Authentik is the identity provider. Declaring modules.services.authentik.applications.<app> on the host creates the OIDC client, its sops secrets and an Authentik blueprint. Paperless, Forgejo, Tandoor, Grafana, Karakeep, BookOrbit and Shelfarr log in this way.
    
    
    Monitoring
    Prometheus with the node exporter (systemd and ZFS collectors) feeds Grafana, which only accepts Authentik logins. Dashboards are provisioned from JSON: an overview of memory, CPU and both drives, plus one for Soulseek downloads. unifi-poller adds the UniFi network.
    
    
    Containers
    Podman is the backend. Older modules use virtualisation.oci-containers; newer ones use quadlet pods, where the app, its Postgres and its Redis share one pod and talk over localhost. Renovate bumps the image = "…" tags.

    isos/couchthink.nix · mkIso
    isos/amnesiac · mkLiveIso
    
    
    The spec
    { host = "couchthink"; offline = true; }
    { kind = "live"; modules = [ ./system.nix ]; }
    
    
    What boots
    A minimal console with nmtui and one command, install-couchthink
    A full LXQt desktop, logged in as amnesia
    
    
    What it does
    Wipes the disks from the host's disko layout (you type ERASE), then runs nixos-install. Offline mode embeds the whole system, so no network is needed.
    Sends all TCP and DNS through Tor with an nftables kill switch, randomises MAC addresses, and runs from a read-only image with a RAM overlay.
    
    
    Afterwards
    The machine is couchthink; the stick is no longer needed
    Nothing survives power-off, unless you set up the optional encrypted persistence partition on the same stick
    
  
    

  
    
    
    Upgrade tests tests/upgrade/tandoor.nix · paperless.nix
    
    
    Renovate bumps container images, and a new image can break a database migration. These NixOS VM tests catch that before it reaches klaus:
    
    
      
      
    1. Boot a VM on the old specialisation, which pins the previous image (Tandoor 2.4.0, Paperless 2.13.5), and let it create its Postgres database.
      2. 
      
    2. Switch the same VM to the module's current image, against the same data.
      3. 
      
    3. Request an API endpoint that touches the database. 200, 401 or 403 pass; a 500 means the migration broke.
